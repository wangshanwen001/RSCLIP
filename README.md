# RSCLIP
The code implementation of the RSCLIP.
![rsclip](docs/rsclip.png)

### Environment
---
```
pip install -r requirements.txt
```

### Demo
---
```
python3 demo_rsclip.py
python3 demo_mask.py
```

### Evaluation

```
python3 eval.py
python3 t_test.py
```
